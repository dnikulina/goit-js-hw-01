# JavaScript Fundamentals — Functions & Calculations

![JavaScript](https://img.shields.io/badge/JavaScript-ES6-yellow?style=flat-square&logo=javascript&logoColor=black)

## Overview

This repository contains introductory JavaScript exercises focused on functions, arithmetic operations, string templates, and numeric conversion.

## Tech Stack

- JavaScript
- HTML
- Git & GitHub

## Tasks

### Transaction Calculator
Calculates the total cost of an order based on quantity and unit price.

### Shipping Cost Message
Calculates the final shipping cost from product price and delivery fee.

### Element Width Calculator
Parses CSS-like pixel values and calculates the full element width including content, padding, and border.

## Learning Outcomes

- declaring and calling functions;
- working with parameters and return values;
- arithmetic operations;
- template literals;
- converting string values to numbers.
